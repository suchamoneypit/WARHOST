This id a unraid server template for running the WARNO dedicated server docker image https://hub.docker.com/r/eugensystems/warno

You must request server keys from Eugen "Any person willing to run a dedicated server must request access by contacting us at eugsupport@eugensystems.com. Please provide the email you used to create your EugNet account. We will send you back a login and apikey pair to use."
They take several days to manually provide you these. You can run 5 servers per key.
